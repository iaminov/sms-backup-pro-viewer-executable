# SMS Backup Viewer & Media Extractor (Portable for Windows)

A fast, offline, standalone Windows viewer and media extractor for XML backups generated by the [SMS Backup & Restore](https://play.google.com/store/apps/details?id=com.riteshsahu.SMSBackupRestore) Android app.

This project integrates the interactive web interface and SQLite indexing of **[lowcarbdev/sbv](https://github.com/lowcarbdev/sbv)** with the file extraction and media classification capabilities of **[danzek/sms-backup-and-restore-parser](https://github.com/danzek/sms-backup-and-restore-parser)** into a unified, zero-configuration portable Windows application.

---

## Key Features

- **100% Offline & Private**: Runs strictly locally on `127.0.0.1`. Your messages and media never leave your machine.
- **Zero Login / Passwordless**: Streamlined for desktop use—no accounts, usernames, or passwords required. Opens directly into your conversations.
- **Full Media Extractor**:
  - Automatically identifies and decodes all base64-encoded media attachments from MMS messages in your backup XML.
  - Organizes files into clean, dedicated subdirectories:
    - 📁 `media/image/` &mdash; Photos (`.jpg`, `.png`, `.gif`, `.heic`, `.webp`, `.bmp`)
    - 📁 `media/video/` &mdash; Videos (`.mp4`, `.3gp`, `.3g2`, `.mov`, `.mkv`, `.webm`)
    - 📁 `media/audio/` &mdash; Voice notes & audio (`.amr`, `.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`)
    - 📁 `media/other/` &mdash; Contact vCards (`.vcf`) and miscellaneous attachments
  - **Timestamp Preservation**: Sets the filesystem modification timestamp (`os.Chtimes`) to match the exact message date and time. When opened in Windows Explorer or photo managers, files are sorted chronologically.
  - **Collision-Safe Naming**: Uses `<timestamp>_<original_name>_<mms_index>-<part_index>.<ext>` naming to ensure no files overwrite each other.
  - **Direct Local Disk Access**: Point the extractor to an XML file path on your drive for instant processing, eliminating HTTP upload overhead on large (1GB–10GB+) backups.
  - **One-Click Folder Access**: Open Windows Explorer straight to your extracted media with the click of a button.
- **Native HEIC / HEIF MMS Decoding**: Uses native `libheif` CGO bindings (`lowcarbdev/libheif-go` and MSYS2 UCRT64 `libheif`) to render Apple HEIC photos in your browser, with an option to export `.jpg` files during media extraction.
- **Streaming Parser**: Handles massive multi-gigabyte XML backup files with constant low memory usage (< 50 MB RAM).
- **Comprehensive Viewer**:
  - Full-text search with SQLite FTS5.
  - Chronological conversation threads and group MMS support.
  - Call logs and call duration analytics.
  - Date range filtering and printable conversation view.

## Quick Start (Prebuilt Portable)

1. Download and extract **`SBV-Windows-Portable.zip`**.
2. Double-click **`Start SBV.cmd`**.
3. Your default browser will open automatically to **`http://127.0.0.1:8085`**.

> **Note**: The portable release contains the native Windows `sbv.exe`, the precompiled React frontend, and all required dynamic libraries (`libheif.dll`, `libde265.dll`, `libx265.dll`, `libaom.dll`, etc.). You do **not** need Go, Node.js, Docker, or MSYS2 installed to run the portable application.

## How to Use

### 1. Viewing Conversations
- In the top navigation bar, click **Upload** to select your `sms-*.xml` or `calls-*.xml` backup file.
- Once indexed, browse your message threads, filter by date, view contacts, or search through messages using full-text search.

### 2. Extracting Media Attachments to Folders
- Click the **Extract Media** button in the top navigation bar (or inside the Upload modal).
- Select your source:
  - **Local XML File**: Enter or paste the file path on your computer (e.g. `C:\Users\Name\Downloads\sms-backup.xml`). This processes directly off the drive without browser upload overhead.
  - **Upload XML File**: Select or drag-and-drop the file through your browser.
- Choose your destination folder (defaults to `./media`).
- Choose which media types to extract (Images, Videos, Audio, and optional HEIC to JPEG conversion).
- Click **Start Extraction**. A live progress bar will show the number of images, videos, and audio notes extracted.
- When finished, click **Open Media Folder in Windows Explorer** to access your categorized files.

## Building from Source (Windows)

The repository includes an automated PowerShell build script that handles all toolchain setup, native dependencies, frontend compilation, and packaging.

### Prerequisites
- Windows 10 or 11 (64-bit)
- PowerShell 5.1 or newer

### Build Steps

1. Clone this repository:
   ```powershell
   git clone https://github.com/iaminov/sms-backup-pro-viewer-executable.git
   cd sms-backup-pro-viewer-executable
   ```
2. Run the builder script:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Build-SBV-Windows.ps1
   ```

The script will automatically:
1. Verify / install prerequisites (**Git, Go, Node.js, and MSYS2**).
2. Install MSYS2 UCRT64 native build dependencies:
   - GCC / CGO compiler
   - `pkg-config`
   - `mingw-w64-ucrt-x86_64-libheif` and codec libraries (`libde265`, `x265`, `aom`, `dav1d`, etc.)
3. Compile the React frontend using `vite build`.
4. Compile `sbv.exe` with CGO build tags `fts5 heic`.
5. Recursively discover and bundle all required native Windows DLLs alongside `sbv.exe`.
6. Package the final standalone distribution into `SBV-Windows-Portable` and `SBV-Windows-Portable.zip`.

## Architecture & Integration

```
                         SMS Backup & Restore XML
                                    │
                                    ▼
                     ┌──────────────────────────────┐
                     │    Streaming XML Decoder     │
                     │ (Constant Low-Memory Footprint)
                     └──────────────┬───────────────┘
                                    │
             ┌──────────────────────┴──────────────────────┐
             ▼                                             ▼
  [Database Ingestion Engine]                   [Media Extraction Engine]
  (Adapted from lowcarbdev/sbv)                 (Adapted from danzek/sbrparser)
             │                                             │
             ├─ SQLite WAL + FTS5 Search                   ├─ Content-Type Classifier
             ├─ Local Passwordless Session                 ├─ Base64 Stream Decoder
             └─ Echo HTTP Server (127.0.0.1)               ├─ Chronological os.Chtimes()
                            │                              ├─ libheif HEIC -> JPEG Converter
                            │                              └─ Subfolder Dispatcher
                            │                                   ├── media/image/
                            ▼                                   ├── media/video/
             ┌──────────────────────────────┐                   └── media/audio/
             │        React Frontend        │                          │
             │   (Vite + React Router SPA)  │                          ▼
             └──────────────┬───────────────┘                Windows File Explorer
                            │
                      Local Browser
                  (http://127.0.0.1:8085)
```
